개인정보 · 비밀키

키는 화면에 입력하지 않습니다.

Anthropic·Google·Qdrant 비밀키는 Cloudflare Worker의 Secret에만 등록합니다. 관리자용 Supabase 키는 사용하지 않습니다.

검토된 근거는 임베딩을 위해 Cloudflare에, 검색 근거와 상품 정보는 생성 요청 시 선택한 제공자(Claude: Anthropic, Gemma: Google)에 전달됩니다. 외부 전송이 허용된 자료만 올리세요.

이 공간의 ‘검토 승인’은 게시 실행이나 수익 발생을 뜻하지 않습니다.

OBSIDIAN · 전용 폴더

콘텐츠 노트 자동 가져오기 · 부분 자동화

ContentCommerce-Inbox 폴더의 최상위 .md만 읽습니다. 개인 볼트·숨김 파일·하위 폴더는 가져오지 않습니다. 본문과 파일명은 Supabase 팀 공간에 검토 전 초안으로 저장됩니다.

새 파일과 수정본은 각각 초안으로 저장합니다. 기존 검토본을 덮어쓰거나 삭제하지 않습니다. AI 생성·검토 승인·색인·발행은 자동 실행하지 않습니다. 탭 닫힘·로그아웃·PC 꺼짐에는 중단되며, 재접속 후 폴더 선택과 시작이 필요합니다.

재시작 안내: 새로고침·페이지 종료 후에는 폴더 재선택 → 시작이 필요합니다. 같은 페이지에서 중지했다면 다시 시작을 누르세요. 중지 중 추가된 노트도 확인하며, 기존 동일본은 서버에서 중복 저장하지 않습니다. 자동화는 초안 가져오기까지만이며 검토 승인·발행·네이버 통계 수집은 자동 실행하지 않습니다.

1. 승인 근거 → 색인 → 생성 큐

선택한 근거 원문 · 출처 검토
목록을 읽고 원문을 선택하세요.
선택한 원문·상품·주제로만 등록합니다. 이미 검토 완료인 자료는 새 검토 요청 없이 등록합니다. 검토만 완료되고 등록이 실패하면 승인은 유지되며 같은 입력으로 재시도할 수 있습니다. 이 버튼은 큐를 켜거나 실행하지 않습니다. 다른 탭에서 이미 켠 큐가 있다면 새 대기 작업이 처리될 수 있습니다.


실패·불확실한 작업도 한도에 포함됩니다. 수동 생성/다른 사용자의 호출/계정 전체 금액을 제한하지 않습니다. 출력 최대 3,072토큰. 제공자 지출 한도는 별도 설정하세요.

3. 공식 글별 조회수 수동 관측
네이버 내 글 통계에서 직접 본 숫자만 입력하세요. 검색 결과 수·블로그 전체 방문자 수·추정치는 사용할 수 없습니다.
진행 중인 날짜는 잠정값만 저장합니다. 미수집은 NULL이며 0으로 채우지 않습니다. 직접 기록한 값은 API 독립 검증값이 아닙니다.
4. 조회수 성과 · 7일 보상
발행일 포함 한국시간 7개 달력일의 일간 조회수 합입니다. 해당 기간이 끝나고 7일 모두 운영자 확정 관측이 있어야 계산합니다. 잠정 0은 최종 보상 0이 아닙니다. RL 자동 학습은 실행하지 않습니다.
기존 학습 데모와 분리된 실서비스 연결용 코드입니다. 생성 후보는 사람 검토 전 초안이며, 매출 또는 학습 성능을 보장하지 않습니다.
